# Desenvolvimento de Software com IA

Área reservada para organizar o curso **Desenvolvimento de Software com IA**.

## Objetivo

Ensinar fundamentos para desenvolver software com ferramentas e agentes de IA,
mesmo para quem ainda tem pouco conhecimento de programação. O curso também
ajudará o aluno a compreender conceitos técnicos, avaliar decisões e se
comunicar melhor com times de desenvolvimento em projetos e entrevistas.

## Estrutura planejada

O sumário inicial possui 15 módulos, começando pelo funcionamento de software e
avançando por ambiente de desenvolvimento, Git, qualidade, segurança,
arquitetura, desenvolvimento com IA, agentes, skills, MCP, aplicações com IA,
workflow profissional, decisões técnicas, projeto prático e preparação
profissional.

O sumário está publicado em `index.html`. As aulas ainda não foram criadas; elas
deverão ser adicionadas aos poucos e seguir o padrão definido em
`MODELO_DE_AULA_IA.md`.
