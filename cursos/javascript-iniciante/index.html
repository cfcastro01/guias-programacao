Aula 1

O que é JavaScript e como pensar sem decorar tudo

Objetivo

Entender para que o JavaScript é usado, aprender a ler um código simples em português e fazer um primeiro teste no console do navegador.

Explicação simples

JavaScript é uma linguagem de programação: uma forma de escrever instruções para o computador. Em uma página, cada tecnologia tem um papel principal:

  • HTML organiza o conteúdo.
  • CSS cuida da aparência.
  • JavaScript cria comportamentos, lógica e interação.

Lógica é a sequência de instruções usada para chegar a um resultado. No começo, você não precisa decorar todos os comandos. O mais importante é entender o que cada linha pede ao computador e saber onde consultar quando tiver dúvida.

Como ler em português

Leia o código como uma sequência de instruções simples: “Guarde o texto Carlos dentro de uma caixinha chamada nome. Depois, mostre no console a mensagem Olá, Carlos.”

Essa “caixinha” é uma variável: um nome usado para guardar um valor. Traduzir cada linha para o português ajuda mais do que tentar decorar o código.

Exemplo comentado

// Guarda um texto na variável nome
const nome = "Carlos";

// Mostra a mensagem no console
console.log("Olá, " + nome);

// Também é possível mostrar um número
console.log(10);

const cria uma variável. O sinal de + junta o texto "Olá, " ao nome guardado. Já console.log() mostra o resultado no console. Textos ficam entre aspas; números, como 10, não precisam delas.

Erros comuns

  • Esquecer as aspas ao escrever um texto.
  • Digitar console.log de forma diferente.
  • Usar nome antes de criar essa variável.

Exercício básico

  1. Crie uma variável com seu nome.
  2. Use esse valor para mostrar uma saudação no formato Olá, nome!, por exemplo Olá, Ana!.
  3. Execute o código abaixo e confira o resultado.

Use qualquer nome. O laboratório procura uma saudação nesse formato e aceita até cinco mensagens extras de apoio.

Resultado

                  
Rascunho salvo neste navegador. Limpar preserva o código. O resultado não bloqueia a conclusão.

                  

                  
                


              

                
Resposta correta

const meuNome = "Ana";

// Mostra a mensagem de boas-vindas
console.log("Olá, " + meuNome + "!");

                  
Explicação da resposta

                  

                    Na primeira linha, const meuNome = "Ana"; cria a
                    variável meuNome e guarda o texto
                    "Ana" nela.
                  

                  

                    Na segunda instrução, console.log() mostra a
                    mensagem. Os sinais de + juntam o começo da
                    frase, o nome guardado e o ponto de exclamação.

                  Aula 2
                  
Variáveis e valores: guardando informações no JavaScript

                


                

                  
Objetivo

                  

                    Entender o que são variáveis, conhecer valores básicos e
                    usar const e let em testes simples
                    no laboratório da página.
                  

                


                

                  
Explicação simples

                  

                    Uma variável guarda uma informação para que possamos usá-la
                    depois. Podemos imaginá-la como uma caixinha com nome, mas
                    isso é apenas uma analogia para facilitar o começo.
                  

                  

                    Em const nome = "Ana";, nome é o
                    nome da variável e "Ana" é o valor guardado.
                    Use const quando esse valor não precisar mudar.
                    Use let quando ele precisar mudar durante o
                    programa.
                  

                  

                    Você também pode encontrar var em códigos
                    antigos. Ele é outra forma de criar variáveis, mas não será
                    nosso foco agora.
                  

                  
Por enquanto, vamos usar três tipos de valor:

                  
    
                    
  • Texto ou string: fica entre aspas, como "Ana".
    • 
                    
  • Número: não usa aspas, como 30.
    • 
                    
  • 
                      Verdadeiro ou falso, chamado booleano:
                      usa true ou false.
                    
    • 
                  

                


                

                  
Como ler em português

                  

                    “Crie uma caixinha chamada nome e guarde o texto Ana.
                      Crie uma caixinha chamada idade e guarde o número 30.
                      Crie uma caixinha chamada estaEstudando e guarde
                      verdadeiro. Depois, mostre esses valores no console.”
                  

                  

                    Para let pontos = 0; e
                    pontos = 10;, leia: “Comece com zero pontos.
                    Depois, troque esse valor por dez.”
                  

                


                

                  
Exemplo comentado

                  
// Valores que não precisam mudar
const nome = "Ana";
const idade = 30;
const estaEstudando = true;

console.log(nome);
console.log(idade);
console.log(estaEstudando);

// Este valor pode mudar
let pontos = 0;
pontos = 10;

console.log(pontos);

                  

                    As três primeiras variáveis usam const. A
                    variável pontos usa let porque seu
                    valor muda de 0 para 10.
                  

                


                

                  
Erros comuns

                  
    
                    
  • Esquecer as aspas em um texto.
    • 
                    
  • Colocar aspas em um número e transformá-lo em texto.
    • 
                    
  • Tentar trocar o valor de uma variável criada com const.
    • 
                    
  • Escrever True ou False com letra maiúscula.
    • 
                  

                


                

                  
Exercício básico

                  
    
                    
  1. Crie uma variável para o nome, com um texto (string).
    2. 
                    
  2. Crie uma variável para a idade, com um número (number).
    3. 
                    
  3. Crie uma variável booleana (boolean) indicando se está estudando JavaScript.
    4. 
                    
  4. Crie uma variável para a pontuação, com um número.
    5. 
                    
  5. Escolha valores reais ou fictícios.
    6. 
                    
  6. Mostre somente os quatro valores no console, nesta ordem: nome, idade, estudando e pontuação.
    7. 
                    
  7. Use uma chamada console.log(variavel) para cada valor, sem rótulos ou mensagens extras.
    8. 
                  

                  
Pratique const para os valores que não precisam mudar e let para a pontuação, que poderá mudar. Use números e true ou false sem aspas.

                  
O laboratório verifica os tipos e a ordem dos valores. Ele não confirma se você usou const, let ou variáveis da forma proposta.

                  
                  
                  

                    
                    
                  

                  
Resultado

                  

                  
Rascunho salvo neste navegador. Limpar preserva o código. O resultado não bloqueia a conclusão.

                  

                  
                


                

                  
Resposta correta


                  

                  

                    
// Escolha valores reais ou fictícios

const minhaIdade = 30;

Explicação da resposta

                    
    
                      
  • const meuNome = "Ana"; guarda um texto.
    • 
                      
  • const minhaIdade = 30; guarda um número.
    • 
                      
  • 
                        const estouEstudandoJavaScript = true; guarda
                        o valor verdadeiro.
                      
    • 
                      
  • 
                        let pontuacao = 0; guarda a pontuação em uma
                        variável que poderá mudar.
                      
    • 
                      
  • 
                        Cada console.log() mostra no console o valor
                        da variável escrita entre os parênteses.

                  Aula 3
                  
Operadores básicos: calculando, comparando e juntando valores

                


                

                  
Objetivo

                  

                    Entender como operadores calculam, juntam e comparam
                    valores, além de começar a fazer perguntas que resultam em
                    true ou false.
                  

                


                

                  
Explicação simples

                  

                    Operadores são símbolos que dizem ao JavaScript o que fazer
                    com os valores. Alguns devolvem um número, outros juntam
                    textos e outros respondem verdadeiro ou falso.
                  

                  
Operadores matemáticos:

                  
    
                    
  • + soma números ou junta textos.
    • 
                    
  • - faz uma subtração.
    • 
                    
  • * faz uma multiplicação.
    • 
                    
  • / faz uma divisão.
    • 
                    
  • % encontra o resto de uma divisão.
    • 
                  

                  

                    O operador = faz uma
                    atribuição: ele guarda um valor em uma
                    variável. Já === compara dois valores e pergunta
                    se eles são exatamente iguais.
                  

                  
Operadores de comparação:

                  
    
                    
  • === pergunta se os valores são iguais.
    • 
                    
  • !== pergunta se os valores são diferentes.
    • 
                    
  • > e < comparam qual valor é maior ou menor.
    • 
                    
  • 
                      >= e <= também aceitam valores
                      iguais na comparação.
                    
    • 
                  

                  
Operadores lógicos:

                  
    
                    
  • && exige que as duas respostas sejam verdadeiras.
    • 
                    
  • || exige que pelo menos uma seja verdadeira.
    • 
                    
  • ! inverte verdadeiro e falso.
    • 
                  

                  

                    Por enquanto, use esses operadores apenas para montar
                    perguntas simples. As decisões com condições serão assunto
                    da próxima aula.
                  

                


                

                  
Como ler em português

                  
    
                    
  • preco - desconto: pegue o preço e tire o desconto.
    • 
                    
  • "Olá, " + nome: junte o texto “Olá” ao nome.
    • 
                    
  • total === 40: total é exatamente igual a 40?
    • 
                    
  • temCadastro && pagou: tem cadastro E pagou?
    • 
                    
  • temCadastro || pagou: tem cadastro OU pagou?
    • 
                    
  • !pagou: inverta a resposta guardada em pagou.
    • 
                  

                


                

                  
Exemplo comentado

                  
// Calcula o preço com desconto
const preco = 50;
const desconto = 10;
const total = preco - desconto;

console.log(total);

// O sinal de + junta textos
const nome = "Ana";
console.log("Olá, " + nome);

// Estas comparações respondem true ou false
console.log(total === 40);
console.log(total > 30);
console.log(total < 30);

// Combina e inverte respostas
const temCadastro = true;
const pagou = false;

console.log(temCadastro && pagou);
console.log(temCadastro || pagou);
console.log(!pagou);

                  

                    Com números, + soma: 2 + 3 resulta
                    em 5. Com textos, ele junta:
                    "Olá, " + "Ana" resulta em
                    "Olá, Ana".
                  

                


                

                  
Erros comuns

                  
    
                    
  • Usar = quando a intenção é comparar com ===.
    • 
                    
  • Esperar uma soma ao usar + com um número entre aspas.
    • 
                    
  • Escrever > = em vez de >=.
    • 
                    
  • Confundir && com ||.
    • 
                  

                


                

                  
Exercício básico

                  
Crie:

                  
    
                    
  • uma variável com o valor de um produto;
    • 
                    
  • uma variável com o valor de um desconto;
    • 
                    
  • uma variável com o preço final;
    • 
                    
  • uma comparação para saber se o preço final é menor que 100;
    • 
                    
  • as variáveis booleanas temCupom e freteGratis;
    • 
                    
  • um teste usando && ou ||.
    • 
                  

                  
Mostre os resultados no console.

                


                

                  
Como testar no console

                  
    
                    
  1. Abra as ferramentas do navegador com F12.
    2. 
                    
  2. Entre na aba Console.
    3. 
                    
  3. Digite as variáveis e pressione Enter.
    4. 
                    
  4. Execute os console.log() e observe os resultados.
    5. 
                  

                  

                    Se você repetir uma variável criada com const e
                    o mesmo nome, o navegador pode mostrar um erro. Recarregue
                    a página e limpe as mensagens do console, ou use outro nome
                    para a variável.
                  

                


                

                  
Resposta correta


                  

                  

                    
const valorProduto = 120;
const valorDesconto = 30;
const precoFinal = valorProduto - valorDesconto;
const custaMenosDeCem = precoFinal < 100;

const temCupom = true;
const freteGratis = false;
const temBeneficio = temCupom || freteGratis;

console.log(precoFinal);
console.log(custaMenosDeCem);
console.log(temBeneficio);

                    
Explicação da resposta

                    
    
                      
  • valorProduto guarda o número 120.
    • 
                      
  • valorDesconto guarda o número 30.
    • 
                      
  • precoFinal guarda o resultado da subtração: 90.
    • 
                      
  • 
                        custaMenosDeCem guarda true,
                        porque 90 é menor que 100.
                      
    • 
                      
  • temCupom guarda verdadeiro.
    • 
                      
  • freteGratis guarda falso.
    • 
                      
  • 
                        temBeneficio guarda true, pois
                        o operador || precisa de apenas uma resposta
                        verdadeira.
                      
    • 
                      
  • Os três console.log() mostram os resultados.
    • 
                    

                  

                




                

                  
Conclusão da aula

                  
                  
Você pode desmarcar esta opção quando quiser.

                

              


              
              

                

                  Aula 4
                  
Condições: fazendo o JavaScript tomar decisões

                


                

                  
Objetivo

                  

                    Entender como usar if, else e
                    else if para executar instruções diferentes de
                    acordo com uma condição.
                  

                


                

                  
Explicação simples

                  

                    Uma condição é uma pergunta que resulta em
                    true ou false. Na Aula 3, você usou
                    comparações e operadores lógicos para formar perguntas.
                    Agora, o JavaScript usará essas respostas para decidir qual
                    trecho do código executar.
                  

                  
    
                    
  • if significa algo próximo de se.
    • 
                    
  • else significa algo próximo de senão.
    • 
                    
  • 
                      else if significa algo próximo de
                      senão, se...
                    
    • 
                  

                  

                    A condição fica entre parênteses. As instruções ficam em um
                    bloco entre chaves { }. O bloco do
                    if só é executado quando sua condição é
                    verdadeira. Se ela for falsa, o JavaScript segue para o
                    próximo else if ou para o else.
                  

                


                

                  
Como ler em português

                  
    
                    
  • 
                      if (idade >= 18): “Se a idade for maior ou
                      igual a 18...”
                    
    • 
                    
  • else: “Senão...”
    • 
                    
  • 
                      else if (nota >= 6): “Senão, se a nota for
                      maior ou igual a 6...”
                    
    • 
                    
  • 
                      temCadastro && pagamentoConfirmado: “Se tem
                      cadastro E o pagamento está confirmado...”
                    
    • 
                  

                  

                    Leia de cima para baixo. Assim que uma condição verdadeira
                    for encontrada, seu bloco é executado e os demais blocos
                    dessa sequência são ignorados.
                  

                


                

                  
Exemplo comentado

                  
const idade = 18;

// Escolhe um dos dois caminhos
if (idade >= 18) {
  console.log("Pode entrar.");
} else {
  console.log("Não pode entrar.");
}

const nota = 7;

// Testa as condições em ordem
if (nota >= 9) {
  console.log("Ótimo");
} else if (nota >= 6) {
  console.log("Aprovado");
} else {
  console.log("Reprovado");
}

const temCadastro = true;
const pagamentoConfirmado = true;

// As duas respostas precisam ser verdadeiras
if (temCadastro && pagamentoConfirmado) {
  console.log("Acesso liberado");
}

                  

                    No primeiro exemplo, apenas uma das duas mensagens aparece.
                    No segundo, o JavaScript testa a nota de cima para baixo e
                    para na primeira condição verdadeira. No último, o bloco só
                    executa quando os dois valores são true.
                  

                  

                    Você também pode usar || quando basta uma das
                    respostas ser verdadeira e ! para inverter uma
                    resposta, como em if (!pagamentoConfirmado).
                  

                


                

                  
Erros comuns

                  
    
                    
  • Usar = para comparar em vez de ===.
    • 
                    
  • Esquecer os parênteses ao redor da condição.
    • 
                    
  • Esquecer as chaves { } do bloco.
    • 
                    
  • Criar uma condição que nunca pode ser verdadeira.
    • 
                    
  • 
                      Colocar primeiro uma condição muito ampla no
                      else if. Por exemplo, testar
                      nota >= 6 antes de nota >= 9.
                    
    • 
                    
  • Confundir &&, que exige as duas respostas, com ||.
    • 
                  

                


                

                  
Exercício básico

                  
    
                    
  1. Comece com const temperatura = 28;. Use if / else if / else para mostrar “Está quente” acima de 30, “Temperatura agradável” entre 20 e 30, ou “Está frio” abaixo de 20.
    2. 
                    
  2. Depois, crie const temIngresso = true; e const documentoValido = true;. Use && em uma condição para mostrar “Entrada permitida” somente quando os dois forem true.
    3. 
                    
  3. Execute o código completo. Com os valores originais, devem aparecer “Temperatura agradável” e “Entrada permitida”, nessa ordem.
    4. 
                  

                  
O laboratório verifica somente a saída, sem comprovar o uso de if, else if, else ou &&. Aceita até cinco logs extras de apoio.

                  
                  
                  

                    
                    
                  

                  
Resultado

                  

                  
Rascunho salvo neste navegador. Limpar preserva o código. A verificação usa os valores originais e não bloqueia a conclusão.

                  

                  
                  
Testes manuais

                  
Troque a temperatura e execute: 31 → “Está quente”; 30 e 20 → “Temperatura agradável”; 19 → “Está frio”. Depois, altere ingresso ou documento para false e confira que “Entrada permitida” não aparece.

                  
Esses testes são manuais: observe a saída mesmo que a verificação indique resultado incorreto. Para a verificação automática, restaure temperatura = 28, temIngresso = true e documentoValido = true antes de clicar em Executar.

}

  console.log("Entrada permitida");
}

                    
Explicação da resposta

    •

    • 
                      
  •

    • 
                      
  • 
                        A ordem é importante: a pergunta sobre mais de 30 vem
                        antes da pergunta sobre 20 ou mais.
                      
    • 
                      
  • 
                        Na última condição, && exige que
                        temIngresso e documentoValido
                        sejam verdadeiros para mostrar a mensagem.
                      
    •

                  Aula 5
                  
Funções: criando instruções para usar quando precisar

                


                

                  
O que é uma função?

                  
Uma função reúne instruções sob um nome para reutilizá-las. Nesta aula, você vai criar funções, chamá-las e passar informações para elas.

                  
function mostrarMensagem() {
  console.log("Olá!");
}

mostrarMensagem();

                


                

                  
Como ler em português

                  
    
                    
  • function mostrarMensagem(): “Crie uma função chamada mostrarMensagem”.
    • 
                    
  • { }: “Guarde aqui as instruções da função”.
    • 
                    
  • mostrarMensagem(): “Execute a função agora”.
    • 
                  

                  
Na definição, os parênteses recebem os parâmetros; na chamada, indicam a execução. As chaves guardam o que a função faz.

                


                

                  
Como usar

                  
Um parâmetro é uma informação que a função espera receber. O valor entregue na chamada é o argumento: abaixo, nome é o parâmetro; Ana e Carlos são argumentos.

                  
function cumprimentar(nome) {
  console.log("Olá, " + nome);
}

cumprimentar("Ana");
cumprimentar("Carlos");

                  
Leia cumprimentar("Ana"): “Execute cumprimentar e entregue Ana como nome”. A mesma função trabalha com valores diferentes.

                  
    
                    
  • mostrarMensagem() executa agora.
    • 
                    
  • mostrarMensagem é uma referência à função, para usá-la depois.
    • 
                  

                  
botao.addEventListener("click", mostrarMensagem);

                  
Leia: “Quando houver um clique, execute mostrarMensagem”. Aqui não usamos (), pois a execução deve esperar o clique. Eventos e funções sem nome (anônimas) serão retomados nas aulas sobre a página.

                  
Cuidados: definir uma função não a executa. Confira os parênteses, o fechamento das chaves e o nome do parâmetro usado dentro dela.

                


                

                  
Exercício básico

                  
    
                    
  1. Crie uma função chamada apresentarPessoa.
    2. 
                    
  2. Ela deve receber um parâmetro chamado nome.
    3. 
                    
  3. Dentro dela, mostre "Olá, " + nome + "!" no console.
    4. 
                    
  4. Teste a função com Ana e Carlos. Ela deve funcionar com qualquer nome.
    5. 
                  

                  
                  
                  

                    
                    
                  

                  
Resultado

                  

                  
Rascunho salvo neste navegador. Limpar preserva o código. O laboratório testa outros nomes e não bloqueia a conclusão.

                  

                  
                  
Complemento opcional

                  
Crie mostrarAviso() para mostrar "Atenção!" e chame a função. Este complemento não faz parte dos testes.

                


                

                  
Resposta correta

}

apresentarPessoa("Ana");
apresentarPessoa("Carlos");

function mostrarAviso() {
  console.log("Atenção!");
}

mostrarAviso();

                    
Explicação da resposta

                    
    
                      
  • 
                        function apresentarPessoa(nome) cria a
                        função e define nome como parâmetro.
                      
    • 
                      
  • 
                        As chaves guardam a instrução que junta “Olá”, o nome
                        recebido e o ponto de exclamação.
                      
    • 
                      
  • 
                        apresentarPessoa("Ana") chama a função e
                        entrega "Ana" como argumento.
                      
    • 
                      
  •

const frutas = ["Maçã", "Banana", "Uva"];

Objetivo

    •

    •

    • 
                    
  • () executa o método;
    • 
                    
  • "Laranja" é a informação entregue ao método.
    •

Objetivo

Explicação simples

                  
Imagine que temos uma lista de frutas:

                  
const frutas = ["Maçã", "Banana", "Uva"];

console.log(frutas[1]);

                    dezenas ou centenas. Além de escrever muitos comandos,
                    precisaríamos adicionar outro console.log()
                    sempre que a lista crescesse.
                  

                  

                    Percorrer uma lista significa visitar seus
                    itens, um depois do outro. Queremos dizer ao JavaScript:

frutas.forEach(function (fruta) {
  console.log(fruta);
});

                    função que recebeu uma vez para cada item da lista. Essa
                    função não tem nome, por isso é chamada de
                    função anônima.

frutas

                    
É o array que queremos percorrer.

                    
.forEach

                    

                      É o método do array. Podemos ler seu nome como “para cada
                      item”.
                    

                    
function (fruta)

                    
É a função executada para cada item.

                    
fruta

                    
É o parâmetro que representa o item atual da lista.

                    
{ ... }

                    
Contém o que deve acontecer com cada item.

Na Aula 5 vimos algo conceitualmente parecido:

                  
botao.addEventListener("click", mostrarMensagem);

                  
Agora vemos:

                  
frutas.forEach(function (fruta) {
  console.log(fruta);
});

                  

                    Nos dois casos, uma função é entregue para outro código
                    executar no momento adequado. No forEach, o
                    JavaScript executa essa função uma vez para cada item da
                    lista.
                  

                  

                    Você poderá encontrar o nome callback para
                    esse tipo de função em códigos e documentações. Vamos
                    aprofundar isso somente mais adiante.
                  


                  
Parênteses dentro de parênteses

                  
Podemos reorganizar o mesmo código para enxergar as partes:

                  
frutas.forEach(
  function (fruta) {
    console.log(fruta);
  }
);

                  
    
                    
  • 
                      Os parênteses externos pertencem ao
                      forEach(...).
                    
    • 
                    
  • Dentro deles, estamos entregando uma função.
    • 
                    
  • 
                      Os parênteses de function (fruta) pertencem à
                      função.
                    
    • 
                    
  • 
                      fruta é a informação que a função recebe.
                    
    • 
                    
  • 
                      As chaves {} guardam as instruções da função.
                    
    • 
                    
  • 
                      No final, ); fecha a chamada do
                      forEach.
                    
    • 
                  

                  

                    É a mesma ideia de entregar uma função vista na Aula 5,
                    agora escrita diretamente dentro dos parênteses do método.
                  

                


                

                  
Como ler em português

                  
frutas.forEach(function (fruta) {
  console.log(fruta);
});

                  
Leia aproximadamente assim:

                  

                    

                      Para cada item da lista frutas, chame esse item de fruta
                      e mostre fruta no console.
                    

                  

                  

                    fruta não é uma palavra especial do JavaScript.
                    É um nome escolhido pelo programador para o parâmetro. Os
                    exemplos abaixo fazem a mesma coisa:
                  

                  
frutas.forEach(function (item) {
  console.log(item);
});

frutas.forEach(function (nomeDaFruta) {
  console.log(nomeDaFruta);
});

                  

                    Um nome claro ajuda a entender o código, mas ele não precisa
                    ser igual ao nome do array.
                  

                


                

                  
Exemplo comentado

  "Fazer exercício",
  "Revisar aula"

Fazer exercício
Revisar aula

                  

                    Podemos mudar a ação feita em cada execução. Aqui, o array
                    continua igual; apenas acrescentamos um texto na saída:
                  

                  
tarefas.forEach(function (tarefa) {
  console.log("Tarefa: " + tarefa);
});

Tarefa: Estudar JavaScript
Tarefa: Fazer exercício
Tarefa: Revisar aula

tarefas.forEach(function (tarefa, indice) {
  console.log(indice, tarefa);
});

                  

                    tarefa representa o item atual e
                    indice representa sua posição. Como vimos na
                    Aula 6, o primeiro índice é 0.
                  

                  

                    O forEach é usado principalmente para executar
                    uma ação para cada item. Ele não cria uma nova lista. Na
                    próxima aula veremos métodos que conseguem criar novas
                    listas a partir de uma lista existente.

                  Aula 10
                  
Transformando e filtrando listas com map e filter

                


                

                  
Objetivo

                  

                    Entender a diferença entre percorrer, transformar e
                    selecionar itens de uma lista usando forEach,
                    map e filter.
                  

                


                

                  
Explicação simples

                  
Retomando forEach

                  
Na Aula 9, percorremos uma lista assim:

                  
const numeros = [1, 2, 3];

numeros.forEach(function (numero) {
  console.log(numero);
});

                  

                    forEach executa uma ação para cada item. Ele é
                    útil quando queremos mostrar algo ou executar uma instrução
                    para cada valor.
                  

                  

                    Mas e se quisermos criar uma nova lista com os valores
                    modificados? É aí que entra o map.
                  


                  
map: transformar cada item

                  
const numeros = [1, 2, 3];

const dobrados = numeros.map(function (numero) {
  return numero * 2;
});

console.log(dobrados);

                  
O resultado é uma nova lista:

                  
[2, 4, 6]

                  
    
                    
  • numeros continua sendo [1, 2, 3];
    • 
                    
  • map percorre cada item;
    • 
                    
  • a função transforma o item atual;
    • 
                    
  • 
                      return informa qual valor entrará na nova
                      lista;
                    
    • 
                    
  • dobrados recebe a nova lista.
    • 
                  


                  
O papel de return

                  
return numero * 2;

                  
Podemos ler essa linha assim:

                  

                    
Devolva o resultado de número vezes dois.

                  

                  

                    Dentro do map, cada valor devolvido por
                    return é colocado na nova lista. Por enquanto,
                    essa é a ideia de return que precisamos.
                  


                  
A lista original não muda

                  
const numeros = [1, 2, 3];

const dobrados = numeros.map(function (numero) {
  return numero * 2;
});

console.log(numeros);
console.log(dobrados);

                  
O console mostra:

                  
[1, 2, 3]
[2, 4, 6]

                  

                    map usa os itens da lista original para montar
                    outra lista. Ele não troca automaticamente os valores de
                    numeros.
                  


                  
filter: selecionar alguns itens

                  
Agora temos uma lista de idades:

                  
const idades = [12, 18, 25, 15, 30];

                  
Queremos uma nova lista somente com maiores de idade:

                  
const maioresDeIdade = idades.filter(function (idade) {
  return idade >= 18;
});

console.log(maioresDeIdade);

                  
O resultado é:

                  
[18, 25, 30]

                  

                    filter também percorre a lista. Para cada item,
                    a função responde true ou false:
                  

                  
    
                    
  • true: o item entra na nova lista;
    • 
                    
  • false: o item fica de fora.
    • 
                  


                  
Retomando condições

                  
Na Aula 4, vimos que esta comparação é uma pergunta:

                  
idade >= 18

                  

                    Ela já resulta em true ou false. No
                    filter, essa resposta decide se o valor entra na
                    nova lista. Por isso podemos escrever diretamente:
                  

                  
return idade >= 18;


                  
forEach, map e filter

                  
Compare os três métodos usando a mesma lista:

                  
const numeros = [1, 2, 3, 4];

numeros.forEach(function (numero) {
  console.log(numero);
});

const dobrados = numeros.map(function (numero) {
  return numero * 2;
});

const maioresQueDois = numeros.filter(function (numero) {
  return numero > 2;
});

                  
    
                    
  • forEach: fazer uma ação para cada item;
    • 
                    
  • 
                      map: transformar cada item e criar uma nova
                      lista;
                    
    • 
                    
  • 
                      filter: selecionar itens e criar uma nova
                      lista.
                    
    • 
                  

                  

                    Para começar, lembre: fazer, transformar e
                    selecionar. Essa é uma orientação didática inicial
                    para escolher entre os três métodos.
                  


                  
Parênteses dentro de parênteses

                  
Podemos abrir o código para enxergar suas partes:

                  
numeros.map(
  function (numero) {
    return numero * 2;
  }
);

                  
    
                    
  • map(...) é a chamada do método;
    • 
                    
  • dentro dela, entregamos uma função;
    • 
                    
  • numero representa o item atual;
    • 
                    
  • as chaves {} contêm as instruções;
    • 
                    
  • 
                      return devolve o valor que entrará na nova
                      lista.
                    
    • 
                  

                  

                    Em filter, a estrutura é a mesma. A diferença é
                    que o return devolve uma resposta verdadeira ou
                    falsa para decidir se o item será mantido.
                  

                


                

                  
Como ler em português

                  
numeros.map(function (numero) {
  return numero * 2;
});

                  

                    

                      Para cada número da lista numeros, devolva o número vezes
                      dois e crie uma nova lista com esses resultados.
                    

                  


                  
idades.filter(function (idade) {
  return idade >= 18;
});

                  

                    

                      Para cada idade da lista, mantenha somente aquelas em que
                      idade maior ou igual a 18 for verdadeiro.
                    

                  

                  

                    Assim como no forEach, numero e
                    idade são nomes escolhidos pelo programador para
                    representar o item atual.
                  

                


                

                  
Exemplo comentado

                  
const precos = [10, 20, 30];

const precosComDesconto = precos.map(function (preco) {
  return preco - 5;
});

console.log(precos);
console.log(precosComDesconto);

const valoresAltos = precos.filter(function (preco) {
  return preco >= 20;
});

console.log(valoresAltos);

                  
O resultado será:

                  
[10, 20, 30]
[5, 15, 25]
[20, 30]

                  

                    map subtraiu cinco de cada preço para produzir
                    outra lista. filter manteve somente os preços
                    maiores ou iguais a vinte. A lista precos
                    continuou igual.
                  

                


                

                  
Erros comuns

                  
    
                    
  • 
                      Esquecer return dentro do map. Sem
                      o valor devolvido, cada posição da nova lista recebe
                      undefined, indicando que nenhum valor foi
                      devolvido.
                    
    • 
                    
  • 
                      Esperar que map altere automaticamente o array
                      original.
                    
    • 
                    
  • 
                      Achar que filter transforma os valores. Ele
                      seleciona quais valores serão mantidos.
                    
    • 
                    
  • 
                      Achar que map remove itens. Ele produz um novo
                      valor para cada item percorrido.
                    
    • 
                    
  • 
                      Esquecer que filter precisa de uma condição
                      que resulte em verdadeiro ou falso.
                    
    • 
                    
  • Confundir quando usar forEach, map ou filter.
    • 
                    
  • Esquecer o ponto antes do nome do método.
    • 
                    
  • Esquecer os parênteses da chamada do método.
    • 
                    
  • 
                      Confundir o parâmetro, que representa o item atual, com a
                      lista inteira.
                    
    •

                  Aula 11
                  
DOM: encontrando elementos do HTML

                


                

                  
Objetivo

                  

                    Entender o que é DOM, encontrar elementos da página pelo ID
                    ou por um seletor simples e ler o texto desses elementos.
                  

                


                

                  
Explicação simples

                  

                    Até agora, testamos os exemplos principalmente no console.
                    Imagine uma página com este HTML:
                  

                  
<h1 id="titulo">Meu curso</h1>
<p class="descricao">Estou aprendendo JavaScript.</p>

                  

                    O JavaScript pode encontrar esses elementos e trabalhar com
                    eles. A primeira etapa é saber como localizá-los.
                  


                  
O que é DOM?

                  

                    DOM significa Document Object Model. Você
                    não precisa memorizar esse nome. Quando o navegador abre um
                    HTML, ele organiza os elementos da página em uma estrutura
                    que o JavaScript consegue acessar. Chamamos essa
                    representação de DOM.
                  

                  
document
└── body
    ├── h1
    └── p

                  

                    Essa é apenas uma forma visual de imaginar a organização:
                    dentro do documento existe o corpo da página, com o título
                    e o parágrafo. O HTML descreve o conteúdo; o DOM é a
                    representação desse conteúdo no navegador.
                  


                  
document: a página carregada

                  
console.log(document);

                  

                    document representa a página carregada no
                    navegador. Podemos ler: “Mostre no console o documento da
                    página”.
                  


                  
Encontrando pelo ID

                  
const titulo = document.getElementById("titulo");

console.log(titulo);

                  
    
                    
  • document representa a página;
    • 
                    
  • 
                      getElementById() é um método para procurar um
                      elemento pelo ID;
                    
    • 
                    
  • "titulo" é o ID que queremos encontrar;
    • 
                    
  • 
                      titulo é a variável em que guardamos uma
                      referência ao elemento encontrado: uma forma de acessá-lo
                      novamente no código.
                    
    • 
                  

                  

                    Em HTML, o ID identifica um elemento e deve ser único na
                    página. O console pode mostrar algo parecido com:
                  

                  
<h1 id="titulo">Meu curso</h1>

                  

                    A variável representa o elemento encontrado, e não apenas
                    o texto "Meu curso".
                  


                  
Lendo o texto com textContent

                  
console.log(titulo.textContent);

                  
Agora o resultado é somente o texto:

                  
Meu curso

                  

                    titulo representa o elemento.
                    .textContent acessa o texto dele. Como vimos na
                    Aula 8, isso é uma propriedade: uma
                    informação, sem parênteses. Nesta aula, vamos apenas ler
                    essa informação.
                  


                  
Encontrando com querySelector

                  
const descricao = document.querySelector(".descricao");

                  

                    querySelector() procura o primeiro elemento
                    que corresponde a um seletor CSS. Um
                    seletor é uma forma de indicar qual elemento procuramos,
                    como fazemos ao aplicar estilos:
                  

                  
    
                    
  • #titulo: um ID;
    • 
                    
  • .descricao: uma classe;
    • 
                    
  • p: uma tag, neste caso um parágrafo.
    • 
                  

                  
document.querySelector("#titulo");
document.querySelector(".descricao");
document.querySelector("p");

                  

                    Uma classe pode aparecer em vários elementos. Se houver
                    mais de um elemento correspondente, querySelector
                    encontra apenas o primeiro na ordem da página.
                  


                  
getElementById e querySelector

                  
document.getElementById("titulo");
document.querySelector("#titulo");

                  

                    Os dois exemplos encontram o mesmo elemento.
                    getElementById procura especificamente um ID:
                    escrevemos seu nome sem #.
                    querySelector recebe um seletor: para um ID,
                    usamos #; para uma classe,
                    .; para uma tag, seu nome.
                  

                  

                    Se você já possui um ID específico, getElementById
                    é direto. querySelector é mais flexível e usa
                    seletores parecidos com CSS.
                  


                  
Quando o elemento não existe

                  
const botao = document.querySelector(".botao-inexistente");

console.log(botao);

                  
Se essa classe não estiver na página, o resultado será:

                  
null

                  

                    null indica que nenhum elemento foi encontrado.
                    Confira o HTML e o seletor antes de tentar ler
                    textContent: não há texto de um elemento para
                    acessar quando a busca não encontrou nada.
                  

                


                

                  
Como ler em português

                  
const titulo = document.getElementById("titulo");

                  

                    “Na página, encontre o elemento com ID titulo e guarde na
                    variável titulo”.
                  

                  
const descricao = document.querySelector(".descricao");

                  

                    “Na página, encontre o primeiro elemento com a classe
                    descricao e guarde na variável descricao”.
                  

                  
console.log(titulo.textContent);

                  

                    “Mostre no console o texto que está dentro do elemento
                    titulo”.
                  

                  

                    Os conceitos anteriores começam a trabalhar juntos:
                    const cria a variável que guarda a referência;
                    document.querySelector() é um método que faz a
                    busca; titulo.textContent é uma propriedade
                    que informa o texto.

                  Aula 12
                  
Eventos: reagindo a cliques e outras ações

                


                

                  
Objetivo

                  

                    Fazer o JavaScript reagir a um clique ou à digitação,
                    conectando um elemento do DOM a uma função com
                    addEventListener.
                  

                


                

                  
Explicação simples

                  
Na Aula 11, aprendemos a encontrar elementos como este:

                  
<button id="botao">Clique aqui</button>

                  
const botao = document.getElementById("botao");

                  
Agora queremos dizer:

                  

                    
Quando a pessoa clicar neste botão, faça alguma coisa.

                  


                  
O que é um evento?

                  

                    Um evento é algo que acontece na página:
                    um clique, uma digitação, uma mudança de valor, o envio de
                    um formulário ou um movimento do mouse. O navegador percebe
                    o que aconteceu e o JavaScript pode reagir. Vamos praticar
                    apenas clique e digitação nesta aula.
                  


                  
addEventListener: registrando uma reação

                  
Na Aula 5, vimos conceitualmente esta instrução:

                  
botao.addEventListener("click", mostrarMensagem);

                  
    
                    
  • botao é o elemento encontrado no DOM;
    • 
                    
  • o ponto . acessa um método desse elemento;
    • 
                    
  • 
                      addEventListener() registra uma função para
                      responder a um evento, como se ficasse esperando por ele;
                    
    • 
                    
  • "click" é o evento observado;
    • 
                    
  • 
                      mostrarMensagem é a função que será executada
                      quando acontecer o clique.
                    
    • 
                  


                  
Passar a função ou executá-la agora?

                  
botao.addEventListener("click", mostrarMensagem);

                  

                    mostrarMensagem, sem (), entrega a
                    função para o navegador executar depois, quando o evento
                    acontecer.
                  

                  
Compare com esta escrita, que não serve para esse objetivo:

                  
botao.addEventListener("click", mostrarMensagem());

                  

                    mostrarMensagem(), com (), executa
                    a função imediatamente, enquanto essa linha é executada,
                    antes de qualquer clique. O resultado dessa chamada é
                    passado ao método, em vez da própria função. Aqui queremos
                    entregar a função, não chamá-la nesse momento.
                  


                  
Uma função nomeada

                  
Em uma página com este botão:

                  
<button id="botao">Mostrar mensagem</button>

                  
const botao = document.getElementById("botao");

function mostrarMensagem() {
  console.log("O botão foi clicado!");
}

botao.addEventListener("click", mostrarMensagem);

                  
    
                    
  1. O JavaScript encontra o botão.
    2. 
                    
  2. Define a função mostrarMensagem.
    3. 
                    
  3. Registra essa função como resposta ao clique.
    4. 
                    
  4. O navegador espera o evento.
    5. 
                    
  5. A função executa quando a pessoa clica.
    6. 
                  

                  

                    Definir uma função não executa suas instruções. Neste
                    exemplo, a mensagem só aparece no console ao clicar. Cada
                    novo clique executa a função novamente.
                  


                  
Uma função anônima

                  
Como alternativa ao registro anterior, podemos escrever:

                  
botao.addEventListener("click", function () {
  console.log("O botão foi clicado!");
});

                  

                    A ideia é a mesma, mas a função está escrita diretamente
                    dentro do método e não tem nome: é uma função anônima.
                    Na Aula 9, também entregamos uma função ao
                    forEach. A diferença é que ele a executa ao
                    percorrer a lista; aqui, ela executa quando ocorre o evento.
                  


                  
Parênteses dentro de parênteses

                  
botao.addEventListener(
  "click",
  function () {
    console.log("O botão foi clicado!");
  }
);

                  
    
                    
  • Os parênteses externos são a chamada de addEventListener.
    • 
                    
  • 
                      "click" é o primeiro argumento, ou seja, a
                      primeira informação entregue ao método.
                    
    • 
                    
  • A função é o segundo argumento.
    • 
                    
  • 
                      Os () de function () são o espaço
                      dos parâmetros, vazio neste exemplo.
                    
    • 
                    
  • As chaves {} guardam as instruções da função.
    • 
                    
  • ); fecha a chamada do método.
    • 
                  


                  
Uma reação que aparece na página

                  
<button id="botao">Clique aqui</button>
<p id="mensagem">Nenhum clique ainda.</p>

  mensagem.textContent = "Você clicou no botão!";
}

                    Na Aula 11, lemos textContent. Agora usamos
                    = para atribuir um novo texto à propriedade.
                    O clique acontece, a função executa, a propriedade recebe
                    o texto e a mensagem na página muda.

                    "input" acontece quando o conteúdo do campo
                    muda durante a digitação. .value é a propriedade
                    que acessa o valor digitado. A função copia esse valor para
                    o texto do parágrafo, inclusive quando apagamos letras.

                  Aula 13
                  
Classes e estados visuais

                


                

                  
Objetivo

                  

                    Usar classes CSS para representar estados da interface,
                    adicionando, removendo, alternando e verificando classes
                    com classList.
                  

                


                

                  
Explicação simples

                  
Imagine um botão e uma mensagem:

                  
<button id="botao">Alternar destaque</button>
<p id="mensagem">Mensagem importante</p>

                  
No CSS, temos uma regra para destacar o parágrafo:

                  
.destaque {
  font-weight: bold;
  background: #eee;
}

                  

                    Queremos que o clique altere a aparência da mensagem. Em
                    vez de mudar várias propriedades CSS pelo JavaScript,
                    podemos adicionar ou remover a classe destaque.
                    O CSS já sabe qual aparência essa classe representa.
                  


                  
O que é um estado visual?

                  

                    Um estado representa como alguma coisa
                    está naquele momento: um menu aberto ou fechado, um botão
                    ativo ou inativo, uma tarefa concluída ou não concluída,
                    um aviso visível ou oculto. O estado visual é a forma como
                    essa situação aparece na interface.
                  

                  
    
                    
  • HTML: organiza a estrutura.
    • 
                    
  • CSS: define a aparência.
    • 
                    
  • JavaScript: decide quando o estado muda.
    • 
                  


                  
classList: as classes do elemento

                  
const mensagem = document.getElementById("mensagem");

console.log(mensagem.classList);

                  

                    mensagem representa o elemento encontrado no
                    DOM. classList é uma propriedade que representa
                    as classes CSS associadas a ele. Ela oferece métodos para
                    trabalhar com essas classes: add(),
                    remove(), toggle() e
                    contains().
                  


                  
Adicionar com add()

                  
mensagem.classList.add("destaque");

                  

                    O elemento passa a ter a classe destaque e a
                    usar as regras CSS definidas para ela. Adicionar uma classe
                    que já está presente mantém essa classe no elemento.
                  


                  
Remover com remove()

                  
mensagem.classList.remove("destaque");

                  

                    A classe é removida do elemento. As regras ligadas a esse
                    destaque deixam de ser aplicadas, mas as outras classes e
                    regras do elemento continuam existindo.
                  


                  
Alternar com toggle()

                  
mensagem.classList.toggle("destaque");

                  
    
                    
  • Se a classe não está presente, adiciona.
    • 
                    
  • Se a classe já está presente, remove.
    • 
                  

                  

                    Essa alternância permite representar dois estados: aberto
                    ou fechado, ativo ou inativo, concluído ou não concluído.
                    Cada chamada troca a presença da classe.
                  


                  
Verificar com contains()

                  
console.log(mensagem.classList.contains("destaque"));

                  

                    A pergunta é: “O elemento mensagem possui a classe
                    destaque?”. A resposta é true quando possui
                    e false quando não possui. Esse método apenas
                    verifica; não altera a classe.
                  


                  
Nomes que representam estados

                  
Por exemplo, o CSS pode definir:

                  
.ativo {
  font-weight: bold;
}

                  
E o JavaScript pode aplicar esse estado ao botão:

                  
botao.classList.add("ativo");

                  

                    Nomes como ativo, aberto e
                    concluido explicam a situação do elemento.
                    Como boa prática inicial, prefira esses nomes quando a
                    classe representar um estado, em vez de nomes apenas
                    visuais, como verde ou grande.
                    Isso não é uma regra absoluta para todas as classes.
                  


                  
Alternar e depois verificar

                  
mensagem.classList.toggle("destaque");

if (mensagem.classList.contains("destaque")) {
  console.log("Destaque ativo");
} else {
  console.log("Destaque inativo");
}

                  

                    toggle() muda o estado.
                    contains() verifica o estado após a mudança.
                    Como vimos na Aula 4, if usa a resposta
                    verdadeira ou falsa para decidir qual instrução executar.
                  


                  
Um exemplo conceitual: menu aberto ou fechado

                  
<button id="menu-botao">Menu</button>

<nav id="menu" class="menu">
  ...
</nav>

                  
.menu {
  display: none;
}

.menu.aberto {
  display: block;
}

                  
const botaoMenu = document.getElementById("menu-botao");
const menu = document.getElementById("menu");

botaoMenu.addEventListener("click", function () {
  menu.classList.toggle("aberto");
});

                  

                    .menu oculta o menu. .menu.aberto
                    corresponde ao elemento que tem as duas classes, e faz o
                    menu aparecer. O JavaScript apenas alterna
                    aberto, mantendo menu.
                    O CSS decide como esse estado deve aparecer.
                  

                  

                    Esse exemplo mostra a ideia de estado. Um menu real também
                    precisa considerar acessibilidade, como uso por teclado e
                    indicação de seu estado para quem utiliza leitor de tela.
                    Esses detalhes serão tratados no momento adequado.

Debug e leitura de erros

                


                

                  
Objetivo

                  
Reconhecer erros comuns, entender a mensagem e corrigir um problema por vez. Fazer debug é investigar por que um programa não funciona como esperado.

                


                

                  
Explicação simples

                  
    
                    
  • Erro de sintaxe: falta ou sobra algo na escrita, como uma aspa ou um parêntese. O JavaScript não consegue interpretar o código e não começa a executá-lo.
    • 
                    
  • Erro em execução: o código começa a rodar, mas uma instrução falha, como usar um nome que não existe. Essa execução é interrompida no erro.
    • 
                    
  • Erro de lógica: o código roda, mas faz algo diferente do esperado. Pode não aparecer nenhuma mensagem de erro.
    • 
                  

                  
A mensagem é uma pista, não uma avaliação sobre você. Não é preciso decorar o texto técnico; procure o tipo de erro, o nome citado e o local indicado.

                


                

                  
Como ler em português

                  
    
                    
  • SyntaxError: “não consegui entender a escrita do código”.
    • 
                    
  • ReferenceError: pontoss is not defined: “não encontrei um nome chamado pontoss”.
    • 
                    
  • TypeError: “essa operação não pode ser feita com o valor recebido”.
    • 
                    
  • Cannot read properties of null: “tentei acessar uma propriedade, mas o valor é null”.
    • 
                  

                  
ReferenceError e TypeError são exemplos de erros que podem surgir durante a execução. As palavras exatas da mensagem variam entre navegadores.

                


                

                  
Rotina básica de diagnóstico

                  
    
                    
  1. Leia a primeira mensagem de erro da sua execução.
    2. 
                    
  2. Localize a linha indicada ou o trecho citado.
    3. 
                    
  3. Confira nomes, aspas, parênteses, chaves e sinais.
    4. 
                    
  4. Corrija uma coisa por vez.
    5. 
                    
  5. Execute novamente e compare com o resultado esperado.
    6. 
                  

                  
No Console, app.js:12:5 indica arquivo, linha 12 e coluna 5. Confira também a linha anterior: o problema pode começar antes do local apontado. No laboratório, procure o trecho pela mensagem; uma referência ao executor não indica uma linha confiável do seu código.

Exemplos comentados: sintaxe, execução e lógica

                  
Aspa não fechada: este texto começa com aspas, mas não termina.

                  
const aviso = "Olá;
// Correção:
const aviso = "Olá";

                  
Compare as versões separadamente. A primeira causa um SyntaxError. O mesmo tipo de erro pode acontecer quando falta fechar ) em console.log("Olá"; ou } em um bloco if.

                  
Nome incorreto: JavaScript diferencia letras e maiúsculas.

                  
const pontos = 10;
console.log(pontoss); // ReferenceError: o nome criado foi pontos

                  
Use pontos, o nome declarado. O mesmo cuidado vale para funções: chamar mostrarAvisoo() em vez de mostrarAviso() pode causar ReferenceError.

                  
Símbolo matemático: ≥ significa “maior ou igual”, mas JavaScript não usa esse símbolo como operador. Escrever idade ≥ 18 causa um SyntaxError. Em JavaScript, escrevemos:

                  
idade >= 18

                  
Erro de lógica: usar > é válido, mas exclui o valor limite.

                  
const pontos = 10;
if (pontos > 10) {
  console.log("Meta atingida");
}

                  
Leia: “se os pontos forem maiores que 10”. Com 10, nada aparece. Se a regra inclui 10, use pontos >= 10. Teste o valor limite para conferir a lógica.

    6. 
                  

                  
Preparar e agir acontecem em momentos diferentes: ao carregar, o código encontra elementos, cria a lista, define a função e registra o evento. No clique, entra na função e executa a condição, a mudança de texto e, se houver itens, a repetição.

                  
Acompanhe de cima para baixo o código que está sendo executado. Ao chegar a uma chamada, siga para o corpo da função e depois retome o ponto da chamada. A posição da definição no arquivo não significa que seu corpo será executado imediatamente.

                  Aula 16
                  
Salvando dados no navegador com localStorage

                


                

                  
Objetivo

                  
Salvar, recuperar e remover informações simples no navegador. Entender como um valor pode continuar disponível depois de recarregar a página.

                


                

                  
Explicação simples

                  
Persistir uma informação é guardá-la para usar depois. Uma variável existe durante a execução: ao recarregar a página, a execução recomeça e seu valor anterior não é preservado. Se o código declarar a variável novamente, ela recebe o valor inicial outra vez.

                  
O localStorage guarda dados localmente e permite buscá-los na próxima visita ou depois de recarregar. Você precisa salvar e recuperar explicitamente; alterar uma variável não atualiza o dado salvo automaticamente.

                  
Esse armazenamento pertence ao navegador e à origem da página: a combinação de protocolo, endereço e porta, como http://localhost:8000. Outro navegador ou outra origem tem seu próprio espaço. Os dados podem ser apagados pelo usuário; não são um banco de dados nem são enviados automaticamente a um servidor.

                  
Cada informação usa uma chave, um nome para encontrá-la, e um valor, o conteúdo guardado. Pense em uma etiqueta e no que ela identifica. Salvar novamente com a mesma chave substitui o valor anterior.

                


                

                  
Como ler em português

                  
    
                    
  • localStorage.setItem("aula-16-nome", "Ana"): “salve no navegador o valor Ana usando a chave aula-16-nome”.
    • 
                    
  • const nomeSalvo = localStorage.getItem("aula-16-nome"): “busque o valor dessa chave e guarde em nomeSalvo”.
    • 
                    
  • localStorage.removeItem("aula-16-nome"): “apague o valor salvo com essa chave”.
    • 
                  

                  
setItem salva, getItem busca e removeItem remove. Usaremos chaves próprias da aula para separar a prática dos dados do site.

                


                

                  
Exemplo comentado: lembrar o nome

                  
1. Salvar: a variável guarda o nome nesta execução; a segunda linha guarda uma cópia no navegador.

                  
const nome = "Ana";
localStorage.setItem("aula-16-nome", nome);

                  
2. Recuperar: depois de recarregar, execute somente este trecho. Em uma página, ele pode fazer parte do código executado ao carregar.

                  
const nomeSalvo = localStorage.getItem("aula-16-nome");
if (nomeSalvo === null) {
  console.log("Ainda não há nome salvo.");
} else {
  console.log("Olá, " + nomeSalvo + "!");
}

                  
Se você salvou Ana, verá Olá, Ana!. Quando a chave não existe, getItem() retorna null, indicando ausência de valor. Isso é diferente do texto "null".

                  
3. Remover: apague apenas a chave usada no exemplo e confira o retorno.

                  
localStorage.removeItem("aula-16-nome");
console.log(localStorage.getItem("aula-16-nome")); // null

                  
Remover o dado salvo não apaga uma variável já carregada. Uma nova busca é que retorna null.

                


                

                  
Evolução curta: salvar uma lista com JSON

                  
O localStorage armazena valores como texto. Mesmo um número salvo diretamente volta como texto. Para preservar a estrutura de um array, usamos JSON, um formato de texto que representa dados.

                  
JSON.stringify() transforma a lista em texto JSON; JSON.parse() transforma esse texto de volta em uma lista. Eles fazem a ponte entre estruturas JavaScript e texto.

                  
const topicos = ["DOM", "Eventos"];
localStorage.setItem("aula-16-topicos", JSON.stringify(topicos));

                  
Para recuperar, inclusive depois de recarregar:

                  
const textoSalvo = localStorage.getItem("aula-16-topicos");
if (textoSalvo !== null) {
  const topicosSalvos = JSON.parse(textoSalvo);
  console.log(topicosSalvos[0]); // DOM
}

                  
Primeiro buscamos texto; depois reconstruímos o array. Neste exemplo, parse recebe o texto criado por stringify. Ele não converte qualquer frase em uma lista: texto que não é JSON válido causa erro.

                


                

                  
Erros comuns

                  
    
                    
  • Salvar com uma chave e tentar buscar com outra: os nomes precisam ser iguais.
    • 
                    
  • Reexecutar o trecho de salvar antes de conferir a persistência: isso grava o dado novamente.
    • 
                    
  • Esperar um número ou array de getItem(): ele retorna texto ou null.
    • 
                    
  • Salvar um array diretamente e esperar recuperar sua estrutura sem JSON.
    • 
                    
  • Achar que mudar uma variável já mudou o armazenamento: é preciso chamar setItem() outra vez.
    • 
                    
  • Evite guardar senhas ou informações sensíveis no localStorage; ele serve aqui apenas para dados simples do navegador.
    •
