Aula 1

O que é JavaScript?

Objetivo

Entender, de forma inicial, para que o JavaScript é usado.

Explicação simples

JavaScript é uma linguagem de programação muito usada para adicionar comportamento e interatividade às páginas da web.

Como ler em português

JavaScript: “djáva-scrípt”.

Exemplo

// Mostra uma mensagem no console
console.log("Olá, mundo!");

Exercício

Altere o exemplo para exibir a mensagem “Estou aprendendo JavaScript!”.

Resposta comentada
console.log("Estou aprendendo JavaScript!");

Mantemos console.log() e trocamos apenas o texto entre aspas, que é a mensagem exibida.
