Aula 1

O que é JavaScript e como pensar sem decorar tudo

Objetivo

Entender para que o JavaScript é usado, aprender a ler um código simples em português e fazer um primeiro teste no console do navegador.

Explicação simples

JavaScript é uma linguagem de programação: uma forma de escrever instruções para o computador. Em uma página, cada tecnologia tem um papel principal:

  • HTML organiza o conteúdo.
  • CSS cuida da aparência.
  • JavaScript cria comportamentos, lógica e interação.

Lógica é a sequência de instruções usada para chegar a um resultado. No começo, você não precisa decorar todos os comandos. O mais importante é entender o que cada linha pede ao computador e saber onde consultar quando tiver dúvida.

Como ler em português

Leia o código como uma sequência de instruções simples: “Guarde o texto Carlos dentro de uma caixinha chamada nome. Depois, mostre no console a mensagem Olá, Carlos.”

Essa “caixinha” é uma variável: um nome usado para guardar um valor. Traduzir cada linha para o português ajuda mais do que tentar decorar o código.

Exemplo comentado

// Guarda um texto na variável nome
const nome = "Carlos";

// Mostra a mensagem no console
console.log("Olá, " + nome);

// Também é possível mostrar um número
console.log(10);

const cria uma variável. O sinal de + junta o texto "Olá, " ao nome guardado. Já console.log() mostra o resultado no console. Textos ficam entre aspas; números, como 10, não precisam delas.

Erros comuns

  • Esquecer as aspas ao escrever um texto.
  • Digitar console.log de forma diferente.
  • Usar nome antes de criar essa variável.

Exercício básico

Crie uma variável com o seu nome e mostre no console uma mensagem de boas-vindas. Por exemplo: “Olá, Ana!”

Como testar no console

  1. Abra as ferramentas do navegador com a tecla F12.
  2. Escolha a aba Console.
  3. Digite ou cole uma linha do código por vez.
  4. Pressione Enter e observe a mensagem.

O console é um espaço de teste: errar e tentar novamente faz parte.

Resposta correta

// Troque Ana pelo seu nome
const meuNome = "Ana";

// Mostra a mensagem de boas-vindas
console.log("Olá, " + meuNome + "!");
Explicação da resposta

Na primeira linha, const meuNome = "Ana"; cria a variável meuNome e guarda o texto "Ana" nela.

Na segunda instrução, console.log() mostra a mensagem. Os sinais de + juntam o começo da frase, o nome guardado e o ponto de exclamação.

Aplicação prática no projeto

Por enquanto, basta reconhecer o papel do JavaScript. Nas próximas etapas dos projetos, ele poderá abrir respostas, reagir a botões e atualizar partes da página. Essas mudanças serão feitas aos poucos, depois que cada conceito necessário for ensinado.

Conclusão da aula

Você pode desmarcar esta opção quando quiser.

Aula 2

Variáveis e valores: guardando informações no JavaScript

Objetivo

Entender o que são variáveis, conhecer valores básicos e usar const e let em testes simples no console.

Explicação simples

Uma variável guarda uma informação para que possamos usá-la depois. Podemos imaginá-la como uma caixinha com nome, mas isso é apenas uma analogia para facilitar o começo.

Em const nome = "Ana";, nome é o nome da variável e "Ana" é o valor guardado. Use const quando esse valor não precisar mudar. Use let quando ele precisar mudar durante o programa.

Você também pode encontrar var em códigos antigos. Ele é outra forma de criar variáveis, mas não será nosso foco agora.

Por enquanto, vamos usar três tipos de valor:

  • Texto ou string: fica entre aspas, como "Ana".
  • Número: não usa aspas, como 30.
  • Verdadeiro ou falso, chamado booleano: usa true ou false.

Como ler em português

“Crie uma caixinha chamada nome e guarde o texto Ana. Crie uma caixinha chamada idade e guarde o número 30. Crie uma caixinha chamada estaEstudando e guarde verdadeiro. Depois, mostre esses valores no console.”

Para let pontos = 0; e pontos = 10;, leia: “Comece com zero pontos. Depois, troque esse valor por dez.”

Exemplo comentado

// Valores que não precisam mudar
const nome = "Ana";
const idade = 30;
const estaEstudando = true;

console.log(nome);
console.log(idade);
console.log(estaEstudando);

// Este valor pode mudar
let pontos = 0;
pontos = 10;

console.log(pontos);

As três primeiras variáveis usam const. A variável pontos usa let porque seu valor muda de 0 para 10.

Erros comuns

  • Esquecer as aspas em um texto.
  • Colocar aspas em um número e transformá-lo em texto.
  • Tentar trocar o valor de uma variável criada com const.
  • Escrever True ou False com letra maiúscula.

Exercício básico

Crie variáveis para guardar:

  • seu nome;
  • sua idade;
  • se você está estudando JavaScript;
  • uma pontuação inicial.

Depois, mostre cada valor no console.

Como testar no console

  1. Abra as ferramentas do navegador com F12.
  2. Entre na aba Console.
  3. Digite ou cole as variáveis uma vez.
  4. Execute cada console.log() e confira o valor mostrado.

Resposta correta

// Troque os valores pelos seus dados
const meuNome = "Ana";
const minhaIdade = 30;
const estouEstudandoJavaScript = true;
let pontuacao = 0;

console.log(meuNome);
console.log(minhaIdade);
console.log(estouEstudandoJavaScript);
console.log(pontuacao);
Explicação da resposta
  • const meuNome = "Ana"; guarda um texto.
  • const minhaIdade = 30; guarda um número.
  • const estouEstudandoJavaScript = true; guarda o valor verdadeiro.
  • let pontuacao = 0; guarda a pontuação em uma variável que poderá mudar.
  • Cada console.log() mostra no console o valor da variável escrita entre os parênteses.

Aplicação prática no projeto

Nos projetos futuros, variáveis poderão guardar o nome de um botão, o texto de uma mensagem, a quantidade de itens, o estado de aberto ou fechado e uma pontuação ou progresso. Essas aplicações serão construídas aos poucos.

Conclusão da aula

Você pode desmarcar esta opção quando quiser.

Aula 3

Operadores básicos: calculando, comparando e juntando valores

Objetivo

Entender como operadores calculam, juntam e comparam valores, além de começar a fazer perguntas que resultam em true ou false.

Explicação simples

Operadores são símbolos que dizem ao JavaScript o que fazer com os valores. Alguns devolvem um número, outros juntam textos e outros respondem verdadeiro ou falso.

Operadores matemáticos:

  • + soma números ou junta textos.
  • - faz uma subtração.
  • * faz uma multiplicação.
  • / faz uma divisão.
  • % encontra o resto de uma divisão.

O operador = faz uma atribuição: ele guarda um valor em uma variável. Já === compara dois valores e pergunta se eles são exatamente iguais.

Operadores de comparação:

  • === pergunta se os valores são iguais.
  • !== pergunta se os valores são diferentes.
  • > e < comparam qual valor é maior ou menor.
  • >= e <= também aceitam valores iguais na comparação.

Operadores lógicos:

  • && exige que as duas respostas sejam verdadeiras.
  • || exige que pelo menos uma seja verdadeira.
  • ! inverte verdadeiro e falso.

Por enquanto, use esses operadores apenas para montar perguntas simples. As decisões com condições serão assunto da próxima aula.

Como ler em português

  • preco - desconto: pegue o preço e tire o desconto.
  • "Olá, " + nome: junte o texto “Olá” ao nome.
  • total === 40: total é exatamente igual a 40?
  • temCadastro && pagou: tem cadastro E pagou?
  • temCadastro || pagou: tem cadastro OU pagou?
  • !pagou: inverta a resposta guardada em pagou.

Exemplo comentado

// Calcula o preço com desconto
const preco = 50;
const desconto = 10;
const total = preco - desconto;

console.log(total);

// O sinal de + junta textos
const nome = "Ana";
console.log("Olá, " + nome);

// Estas comparações respondem true ou false
console.log(total === 40);
console.log(total > 30);
console.log(total < 30);

// Combina e inverte respostas
const temCadastro = true;
const pagou = false;

console.log(temCadastro && pagou);
console.log(temCadastro || pagou);
console.log(!pagou);

Com números, + soma: 2 + 3 resulta em 5. Com textos, ele junta: "Olá, " + "Ana" resulta em "Olá, Ana".

Erros comuns

  • Usar = quando a intenção é comparar com ===.
  • Esperar uma soma ao usar + com um número entre aspas.
  • Escrever > = em vez de >=.
  • Confundir && com ||.

Exercício básico

Crie:

  • uma variável com o valor de um produto;
  • uma variável com o valor de um desconto;
  • uma variável com o preço final;
  • uma comparação para saber se o preço final é menor que 100;
  • as variáveis booleanas temCupom e freteGratis;
  • um teste usando && ou ||.

Mostre os resultados no console.

Como testar no console

  1. Abra as ferramentas do navegador com F12.
  2. Entre na aba Console.
  3. Digite as variáveis e pressione Enter.
  4. Execute os console.log() e observe os resultados.

Se você repetir uma variável criada com const e o mesmo nome, o navegador pode mostrar um erro. Recarregue a página e limpe as mensagens do console, ou use outro nome para a variável.

Resposta correta

const valorProduto = 120;
const valorDesconto = 30;
const precoFinal = valorProduto - valorDesconto;
const custaMenosDeCem = precoFinal < 100;

const temCupom = true;
const freteGratis = false;
const temBeneficio = temCupom || freteGratis;

console.log(precoFinal);
console.log(custaMenosDeCem);
console.log(temBeneficio);
Explicação da resposta
  • valorProduto guarda o número 120.
  • valorDesconto guarda o número 30.
  • precoFinal guarda o resultado da subtração: 90.
  • custaMenosDeCem guarda true, porque 90 é menor que 100.
  • temCupom guarda verdadeiro.
  • freteGratis guarda falso.
  • temBeneficio guarda true, pois o operador || precisa de apenas uma resposta verdadeira.
  • Os três console.log() mostram os resultados.

Aplicação prática no projeto

Nos projetos futuros, operadores poderão calcular totais, verificar se um item está completo, comparar valores, decidir se uma resposta deve aparecer e conferir se uma ação pode acontecer. Essa lógica será construída aos poucos.

Conclusão da aula

Você pode desmarcar esta opção quando quiser.

Aula 4

Condições: fazendo o JavaScript tomar decisões

Objetivo

Entender como usar if, else e else if para executar instruções diferentes de acordo com uma condição.

Explicação simples

Uma condição é uma pergunta que resulta em true ou false. Na Aula 3, você usou comparações e operadores lógicos para formar perguntas. Agora, o JavaScript usará essas respostas para decidir qual trecho do código executar.

  • if significa algo próximo de se.
  • else significa algo próximo de senão.
  • else if significa algo próximo de senão, se...

A condição fica entre parênteses. As instruções ficam em um bloco entre chaves { }. O bloco do if só é executado quando sua condição é verdadeira. Se ela for falsa, o JavaScript segue para o próximo else if ou para o else.

Como ler em português

  • if (idade >= 18): “Se a idade for maior ou igual a 18...”
  • else: “Senão...”
  • else if (nota >= 6): “Senão, se a nota for maior ou igual a 6...”
  • temCadastro && pagamentoConfirmado: “Se tem cadastro E o pagamento está confirmado...”

Leia de cima para baixo. Assim que uma condição verdadeira for encontrada, seu bloco é executado e os demais blocos dessa sequência são ignorados.

Exemplo comentado

const idade = 18;

// Escolhe um dos dois caminhos
if (idade >= 18) {
  console.log("Pode entrar.");
} else {
  console.log("Não pode entrar.");
}

const nota = 7;

// Testa as condições em ordem
if (nota >= 9) {
  console.log("Ótimo");
} else if (nota >= 6) {
  console.log("Aprovado");
} else {
  console.log("Reprovado");
}

const temCadastro = true;
const pagamentoConfirmado = true;

// As duas respostas precisam ser verdadeiras
if (temCadastro && pagamentoConfirmado) {
  console.log("Acesso liberado");
}

No primeiro exemplo, apenas uma das duas mensagens aparece. No segundo, o JavaScript testa a nota de cima para baixo e para na primeira condição verdadeira. No último, o bloco só executa quando os dois valores são true.

Você também pode usar || quando basta uma das respostas ser verdadeira e ! para inverter uma resposta, como em if (!pagamentoConfirmado).

Erros comuns

  • Usar = para comparar em vez de ===.
  • Esquecer os parênteses ao redor da condição.
  • Esquecer as chaves { } do bloco.
  • Criar uma condição que nunca pode ser verdadeira.
  • Colocar primeiro uma condição muito ampla no else if. Por exemplo, testar nota >= 6 antes de nota >= 9.
  • Confundir &&, que exige as duas respostas, com ||.

Exercício básico

Comece com esta variável:

const temperatura = 28;

Escreva uma condição que mostre:

  • “Está quente” se a temperatura for maior que 30;
  • “Temperatura agradável” se ela for maior ou igual a 20;
  • “Está frio” nos demais casos.

Depois, use estes dois valores:

const temIngresso = true;
const documentoValido = true;

Mostre “Entrada permitida” somente quando os dois valores forem true.

Como testar no console

  1. Abra as ferramentas do navegador com F12.
  2. Entre na aba Console.
  3. Cole e execute um bloco completo de cada vez.
  4. Troque os valores e observe qual mensagem aparece.

Repetir uma variável criada com const e o mesmo nome pode gerar um erro. Nesse caso, recarregue a página ou troque o nome da variável antes de testar novamente.

Resposta correta

const temperatura = 28;

if (temperatura > 30) {
  console.log("Está quente");
} else if (temperatura >= 20) {
  console.log("Temperatura agradável");
} else {
  console.log("Está frio");
}

const temIngresso = true;
const documentoValido = true;

if (temIngresso && documentoValido) {
  console.log("Entrada permitida");
}
Explicação da resposta
  • Primeiro, temperatura > 30 pergunta se o valor é maior que 30. Para 28, a resposta é false.
  • Depois, temperatura >= 20 resulta em true. Por isso, aparece “Temperatura agradável”.
  • O else só seria executado se as duas comparações anteriores fossem falsas.
  • A ordem é importante: a pergunta sobre mais de 30 vem antes da pergunta sobre 20 ou mais.
  • Na última condição, && exige que temIngresso e documentoValido sejam verdadeiros para mostrar a mensagem.

Aplicação prática no projeto

Condições poderão mostrar estados diferentes, decidir se uma aula está concluída, validar se uma resposta pode aparecer, verificar se uma ação deve acontecer e alterar mensagens conforme os dados ou as escolhas da pessoa.

O site já usa condições internamente para decidir como exibir alguns estados. O armazenamento desses estados será estudado com mais calma em outro momento.

Conclusão da aula

Você pode desmarcar esta opção quando quiser.

Aula 5

Funções: criando instruções para usar quando precisar

Objetivo

Entender como criar e chamar uma função, entregar uma informação para ela e reconhecer quando uma função deve ser executada agora ou usada depois.

Explicação simples

5.1 — Criando e executando uma função

Uma função é um bloco de instruções que recebe um nome e pode ser usado quando for necessário. Funções ajudam a organizar o código e evitam repetir as mesmas instruções. 

function mostrarMensagem() {
  console.log("Olá!");
}

mostrarMensagem();

A palavra function indica que estamos criando uma função. mostrarMensagem é o nome dela. O código entre as chaves é o bloco de instruções. Na última linha, mostrarMensagem() chama e executa a função.

5.2 — Parâmetros: informações que entram na função

Um parâmetro é uma informação que a função espera receber. Ele permite usar a mesma função com valores diferentes. 

function cumprimentar(nome) {
  console.log("Olá, " + nome);
}

cumprimentar("Ana");
cumprimentar("Carlos");

nome é o parâmetro definido pela função. "Ana" e "Carlos" são argumentos: os valores entregues em cada chamada. Essa diferença de nomes ajuda na leitura, mas o mais importante agora é perceber que o valor entra na função e pode ser usado por suas instruções.

5.3 — Chamar uma função ou passar para usar depois

Compare estas duas formas:

  • mostrarMensagem(): execute a função agora.
  • mostrarMensagem: use a função sem executá-la ainda.

Em códigos futuros, você encontrará instruções como esta: 

botao.addEventListener("click", mostrarMensagem);

Leia: “Quando acontecer um clique, use a função mostrarMensagem”. Ela aparece sem () porque deve ser executada depois, quando o clique ocorrer. O botão e o addEventListener serão estudados em outra aula.

Também é possível encontrar uma função sem nome:

function () {
  console.log("Olá!");
}

Ela é chamada de função anônima. Por enquanto, basta reconhecer esse formato. Assuntos mais avançados sobre funções serão estudados em outros cursos. Funções também podem devolver resultados, mas o return será visto separadamente mais adiante.

Como ler em português

Leia cada parte da primeira função assim:

  • function: “Estou criando uma função”.
  • mostrarMensagem: “Este é o nome da função”.
  • (): “Aqui poderiam entrar parâmetros, que são informações para a função”.
  • { }: “Aqui está o bloco de instruções da função”.
  • mostrarMensagem(): “Execute essa função agora”.

Os parênteses () e as chaves { } têm trabalhos diferentes. Na definição, os parênteses são o espaço dos parâmetros e as chaves guardam as instruções. Na chamada, os parênteses indicam que queremos executar a função.

Leia cumprimentar("Ana") como: “Execute cumprimentar e entregue o texto Ana para ela usar como nome”.

Agora observe os parênteses dentro de outros parênteses:

botao.addEventListener(
  "click",
  function () {
    console.log("Olá!");
  }
);

Essa instrução recebe duas informações:

  1. "click": qual evento observar;
  2. function () { ... }: o que fazer quando acontecer.

Leia o conjunto como: “Quando acontecer um clique, execute estas instruções”. Esse exemplo serve apenas para reconhecer a estrutura; não vamos estudar eventos ou páginas agora.

Exemplo comentado

// Cria a função, mas ainda não mostra nada
function mostrarMensagem() {
  console.log("Olá!");
}

// Executa a função agora
mostrarMensagem();

// O parâmetro nome recebe um valor em cada chamada
function cumprimentar(nome) {
  console.log("Olá, " + nome);
}

cumprimentar("Ana");
cumprimentar("Carlos");

Primeiro, as funções são definidas. Depois, cada par de parênteses nas chamadas faz a função executar. A função cumprimentar reutiliza as mesmas instruções com dois nomes diferentes.

Erros comuns

  • Criar a função, mas esquecer de chamá-la.
  • Escrever apenas mostrarMensagem esperando que ela seja executada imediatamente.
  • Usar mostrarMensagem() quando outra parte do código espera receber a função para executá-la depois.
  • Esquecer () na definição ou na chamada.
  • Confundir o papel de () com o de { }.
  • Esquecer de fechar uma chave.
  • Definir o parâmetro nome, mas usar outro nome dentro da função.

Exercício básico

  1. Crie uma função chamada apresentarPessoa.
  2. Ela deve receber um parâmetro chamado nome.
  3. Dentro dela, mostre "Olá, " + nome + "!" no console.
  4. Chame a função com os nomes Ana e Carlos.

Como complemento, crie e execute esta função:

function mostrarAviso() {
  console.log("Atenção!");
}

mostrarAviso();

Como testar no console

  1. Abra as ferramentas do navegador com F12.
  2. Entre na aba Console.
  3. Cole primeiro a definição completa da função.
  4. Pressione Enter e observe que nada é mostrado ainda.
  5. Chame a função separadamente e pressione Enter.
  6. Teste novamente com valores diferentes.

Apenas definir uma função não executa suas instruções. A mensagem aparece quando você faz a chamada com (). Se repetir uma definição e encontrar um erro, recarregue a página ou troque o nome usado no teste.

Resposta correta

function apresentarPessoa(nome) {
  console.log("Olá, " + nome + "!");
}

apresentarPessoa("Ana");
apresentarPessoa("Carlos");

function mostrarAviso() {
  console.log("Atenção!");
}

mostrarAviso();
Explicação da resposta
  • function apresentarPessoa(nome) cria a função e define nome como parâmetro.
  • As chaves guardam a instrução que junta “Olá”, o nome recebido e o ponto de exclamação.
  • apresentarPessoa("Ana") chama a função e entrega "Ana" como argumento.
  • A segunda chamada reutiliza a função com o argumento "Carlos".
  • mostrarAviso não precisa de parâmetro, mas ainda usa () na definição e na chamada.

Aplicação prática no projeto

Nos projetos, funções poderão abrir ou fechar um menu, mostrar uma mensagem, atualizar um contador, verificar uma informação, reagir a um clique e executar a mesma lógica em lugares diferentes. Essas aplicações serão construídas aos poucos nas próximas etapas.

Conclusão da aula

Você pode desmarcar esta opção quando quiser.

Aula 6

Arrays: trabalhando com listas

Objetivo

Entender como criar uma lista em JavaScript, acessar seus itens pela posição, consultar sua quantidade e adicionar ou remover um item no final.

Explicação simples

Um array é uma lista de valores organizada dentro de uma única variável. Em vez de criar uma variável para cada fruta: 

const fruta1 = "Maçã";
const fruta2 = "Banana";
const fruta3 = "Uva";

podemos guardar os três valores em uma lista:

const frutas = ["Maçã", "Banana", "Uva"];

Os colchetes [] indicam o começo e o fim do array. Dentro deles, os itens são separados por vírgulas. Uma variável simples guarda um valor; nesse exemplo, o array guarda vários valores relacionados.

Cada item ocupa uma posição chamada índice. O primeiro índice é 0: 

frutas[0]  → "Maçã"
frutas[1]  → "Banana"
frutas[2]  → "Uva"

Uma lista com três itens possui os índices 0, 1 e 2. Por isso, frutas[3] aponta para a quarta posição, não para o terceiro item. Como essa posição não existe, o console poderá mostrar undefined, que indica a ausência de um valor ali.

frutas.length informa a quantidade de itens e resulta em 3. length é uma propriedade: uma informação da lista. Já push() e pop() são métodos: ações realizadas na lista. push() adiciona um item no final e pop() remove o último item. Os métodos serão estudados com mais detalhes em outra aula.

Como ler em português

  • const frutas = ["Maçã", "Banana", "Uva"];: “Crie uma lista chamada frutas e guarde nela Maçã, Banana e Uva”.
  • frutas[0]: “Pegue o item da posição zero da lista frutas”.
  • frutas.length: “Informe quantos itens existem na lista frutas”.
  • frutas.push("Laranja"): “Adicione Laranja ao final da lista frutas”.
  • frutas.pop(): “Remova o último item da lista frutas”.

Exemplo comentado

const frutas = ["Maçã", "Banana", "Uva"];

// Mostra a lista completa
console.log(frutas);

// Mostra itens pelas posições zero e um
console.log(frutas[0]);
console.log(frutas[1]);

// Mostra a quantidade: 3
console.log(frutas.length);

// Adiciona Laranja ao final
frutas.push("Laranja");
console.log(frutas);

// Remove o último item
frutas.pop();
console.log(frutas);

No começo, o console mostra as três frutas. Os acessos frutas[0] e frutas[1] mostram Maçã e Banana. Depois do push(), a lista passa a ter quatro itens. O pop() remove Laranja, e a lista volta a ter três itens.

Erros comuns

  • Esquecer os colchetes [] da lista.
  • Esquecer a vírgula entre os itens.
  • Pensar que o primeiro item está no índice 1.
  • Tentar acessar um índice que não existe.
  • Escrever .length() em vez de .length.
  • Esquecer os parênteses em .push() ou .pop().
  • Achar que pop() escolhe qual item remover. Ele sempre remove o último.

Aula 7

Objetos: organizando informações

Objetivo

Entender como criar um objeto, acessar suas propriedades e alterar ou adicionar informações relacionadas à mesma coisa.

Explicação simples

Um objeto agrupa informações que pertencem à mesma coisa. Em vez de manter os dados de uma pessoa em variáveis separadas: 

const nome = "Ana";
const idade = 30;
const estaEstudando = true;

podemos reuni-los em um objeto:

const pessoa = {
  nome: "Ana",
  idade: 30,
  estaEstudando: true
};

As chaves { } indicam o começo e o fim do objeto. nome, idade e estaEstudando são propriedades, também chamadas de chaves. Cada propriedade é seguida por dois-pontos : e pelo seu valor. As propriedades são separadas por vírgulas.

Para acessar uma informação, usamos um ponto entre o objeto e a propriedade: pessoa.nome. Nessa leitura, pessoa é o objeto, o ponto indica que queremos algo dentro dele e nome é a propriedade desejada.

O ponto já apareceu em console.log(), frutas.length e frutas.push(). Por enquanto, vamos usá-lo apenas para acessar propriedades. O assunto será aprofundado na aula de métodos.

Array ou objeto?
const frutas = ["Maçã", "Banana", "Uva"];

const pessoa = {
  nome: "Ana",
  idade: 30
};
  • Um array representa uma lista, e seus itens são acessados principalmente pela posição, como frutas[0].
  • Um objeto reúne informações relacionadas sobre algo, e seus valores são acessados pelo nome da propriedade, como pessoa.nome.

Como explicação inicial, pense assim: um array responde melhor a “quais itens existem nesta lista?”, enquanto um objeto responde melhor a “quais informações descrevem esta coisa?”. Essa comparação ajuda no começo, mas não é uma regra absoluta para todos os programas.

Como ler em português

Para o objeto pessoa, leia:

  • const pessoa = { ... };: “Crie um objeto chamado pessoa. Nele, guarde o nome Ana, a idade 30 e a informação de que está estudando”.
  • pessoa.nome: “Pegue a informação nome do objeto pessoa”.
  • pessoa.idade: “Pegue a idade da pessoa”.
  • pessoa.idade = 31: “Troque a idade da pessoa para 31”.
  • pessoa.cidade = "Rio de Janeiro": “Adicione ao objeto pessoa a informação cidade com o valor Rio de Janeiro”.

Exemplo comentado

const curso = {
  nome: "JavaScript Iniciante",
  aulasDisponiveis: 7,
  gratuito: true
};

// Mostra o objeto completo
console.log(curso);

// Acessa duas propriedades
console.log(curso.nome);
console.log(curso.aulasDisponiveis);

// Altera um valor existente
curso.aulasDisponiveis = 8;
console.log(curso.aulasDisponiveis);

// Adiciona uma nova propriedade
curso.categoria = "Programação";
console.log(curso);

Primeiro, o objeto reúne três informações sobre o curso. O ponto permite mostrar uma propriedade específica. Depois, aulasDisponiveis muda de 7 para 8, e categoria é adicionada ao objeto.

Mesmo criado com const, o objeto pode ter uma propriedade interna alterada. De forma simples: const impede trocar a variável curso por outro valor, mas as informações dentro do objeto ainda podem mudar.

Erros comuns

  • Confundir as chaves { } do objeto com os colchetes [] do array.
  • Esquecer os dois-pontos entre a chave e o valor.
  • Esquecer a vírgula entre as propriedades.
  • Tentar usar pessoa[0] para acessar a primeira propriedade.
  • Escrever um nome de propriedade diferente do que existe.
  • Esquecer o ponto em pessoa.nome.
  • Confundir o sinal = usado para alterar um valor com os dois-pontos usados na criação do objeto.

Exercício básico

Aula 8

Métodos: quando uma coisa faz alguma coisa

Objetivo

Entender o que é um método, diferenciá-lo de uma propriedade e usar ações simples disponíveis em textos e arrays.

Explicação simples

Você já encontrou o ponto em códigos como estes:

frutas.length
frutas.push("Laranja")
console.log("Olá")

O ponto . aparece quando queremos acessar algo relacionado a um valor ou objeto. Para começar, podemos pensar assim:

  • propriedade é uma informação;
  • método é uma ação.
const frutas = ["Maçã", "Banana"];

frutas.length;
frutas.push("Uva");

length informa quantos itens existem. push() executa a ação de adicionar um item. Se a propriedade descreve alguma coisa, o método normalmente faz alguma coisa. Essa é uma simplificação útil para quem está começando, não uma definição completa da linguagem.

Função e método

Na Aula 5, criamos uma função independente:

function cumprimentar(nome) {
  console.log("Olá, " + nome);
}

cumprimentar("Ana");

Agora compare com uma ação disponível em um texto:

const nome = "ana";

nome.toUpperCase();

cumprimentar() é uma função chamada diretamente. toUpperCase() é uma ação disponível no valor de texto. Quando uma função aparece ligada a algo por meio do ponto, chamamos essa função de método.

Propriedade e método lado a lado

Em frutas.length:

  • frutas é a lista;
  • o ponto acessa algo relacionado à lista;
  • length é a informação sobre a quantidade;
  • não usamos ().

Em frutas.push("Laranja"):

  • frutas é a lista;
  • o ponto acessa uma ação disponível;
  • push é a ação de adicionar ao final;
  • () executa o método;
  • "Laranja" é a informação entregue ao método.

Portanto, length é uma propriedade e push() é um método. Essa diferença explica por que algumas palavras depois do ponto usam parênteses e outras não.

Como ler em português

  • nome.toUpperCase(): “Pegue o texto nome e execute a ação de transformá-lo em maiúsculas”.
  • nome.includes("Car"): “Pergunte se o texto nome contém Car”.
  • frutas.push("Laranja"): “Na lista frutas, execute a ação de adicionar Laranja ao final”.
  • frutas.length: “Veja a informação quantidade de itens da lista frutas”.
  • console.log(nome): “No console, execute a ação log para mostrar o valor de nome”.

Você usa console.log() desde a primeira aula. De forma simples, console oferece ferramentas relacionadas ao console e log() é a ação usada para mostrar uma informação. Você já usava um método antes mesmo de conhecer esse nome.

Exemplo comentado

const nome = "Carlos";

console.log(nome);
console.log(nome.toUpperCase());
console.log(nome.toLowerCase());
console.log(nome.includes("Car"));

const frutas = ["Maçã", "Banana"];

console.log(frutas.length);

frutas.push("Uva");
console.log(frutas);

frutas.pop();
console.log(frutas);

toUpperCase() produz "CARLOS", toLowerCase() produz "carlos" e includes("Car") produz true porque o trecho existe no texto.

frutas.length começa mostrando 2. push() adiciona Uva, e pop() remove esse último item. Agora podemos dar nome ao que já vimos na Aula 6: push() e pop() são métodos do array.

Os métodos de texto não precisam alterar a variável original. Depois de mostrar nome.toUpperCase(), a variável nome ainda guarda "Carlos". O método produz o texto em maiúsculas para aquele resultado, mas não troca automaticamente o valor guardado.

Erros comuns

  • Escrever .length() em vez de .length.
  • Esquecer () em um método como .push().
  • Esquecer o ponto antes da propriedade ou do método.
  • Escrever o nome do método incorretamente.
  • Esquecer que JavaScript diferencia letras maiúsculas e minúsculas, como em toUpperCase().
  • Achar que toUpperCase() altera automaticamente a variável original.
  • Tentar usar um método em um tipo de valor que não oferece aquela ação. Textos e arrays podem ter métodos diferentes.
