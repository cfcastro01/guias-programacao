Aula 1

O que é JavaScript e como pensar sem decorar tudo

Objetivo

Entender para que o JavaScript é usado, aprender a ler um código simples em português e fazer um primeiro teste no console do navegador.

Explicação simples

JavaScript é uma linguagem de programação: uma forma de escrever instruções para o computador. Em uma página, cada tecnologia tem um papel principal:

  • HTML organiza o conteúdo.
  • CSS cuida da aparência.
  • JavaScript cria comportamentos, lógica e interação.

Lógica é a sequência de instruções usada para chegar a um resultado. No começo, você não precisa decorar todos os comandos. O mais importante é entender o que cada linha pede ao computador e saber onde consultar quando tiver dúvida.

Como ler em português

Leia o código como uma sequência de instruções simples: “Guarde o texto Carlos dentro de uma caixinha chamada nome. Depois, mostre no console a mensagem Olá, Carlos.”

Essa “caixinha” é uma variável: um nome usado para guardar um valor. Traduzir cada linha para o português ajuda mais do que tentar decorar o código.

Exemplo comentado

// Guarda um texto na variável nome
const nome = "Carlos";

// Mostra a mensagem no console
console.log("Olá, " + nome);

// Também é possível mostrar um número
console.log(10);

const cria uma variável. O sinal de + junta o texto "Olá, " ao nome guardado. Já console.log() mostra o resultado no console. Textos ficam entre aspas; números, como 10, não precisam delas.

Erros comuns

  • Esquecer as aspas ao escrever um texto.
  • Digitar console.log de forma diferente.
  • Usar nome antes de criar essa variável.

Exercício básico

Crie uma variável com o seu nome e mostre no console uma mensagem de boas-vindas. Por exemplo: “Olá, Ana!”

Como testar no console

  1. Abra as ferramentas do navegador com a tecla F12.
  2. Escolha a aba Console.
  3. Digite ou cole uma linha do código por vez.
  4. Pressione Enter e observe a mensagem.

O console é um espaço de teste: errar e tentar novamente faz parte.

Resposta correta

// Troque Ana pelo seu nome
const meuNome = "Ana";

// Mostra a mensagem de boas-vindas
console.log("Olá, " + meuNome + "!");
Explicação da resposta

Na primeira linha, const meuNome = "Ana"; cria a variável meuNome e guarda o texto "Ana" nela.

Na segunda instrução, console.log() mostra a mensagem. Os sinais de + juntam o começo da frase, o nome guardado e o ponto de exclamação.

Aplicação prática no projeto

Por enquanto, basta reconhecer o papel do JavaScript. Nas próximas etapas dos projetos, ele poderá abrir respostas, reagir a botões e atualizar partes da página. Essas mudanças serão feitas aos poucos, depois que cada conceito necessário for ensinado.

Aula 2

Variáveis e valores: guardando informações no JavaScript

Objetivo

Entender o que são variáveis, conhecer valores básicos e usar const e let em testes simples no console.

Explicação simples

Uma variável guarda uma informação para que possamos usá-la depois. Podemos imaginá-la como uma caixinha com nome, mas isso é apenas uma analogia para facilitar o começo.

Em const nome = "Ana";, nome é o nome da variável e "Ana" é o valor guardado. Use const quando esse valor não precisar mudar. Use let quando ele precisar mudar durante o programa.

Você também pode encontrar var em códigos antigos. Ele é outra forma de criar variáveis, mas não será nosso foco agora.

Por enquanto, vamos usar três tipos de valor:

  • Texto ou string: fica entre aspas, como "Ana".
  • Número: não usa aspas, como 30.
  • Verdadeiro ou falso, chamado booleano: usa true ou false.

Como ler em português

“Crie uma caixinha chamada nome e guarde o texto Ana. Crie uma caixinha chamada idade e guarde o número 30. Crie uma caixinha chamada estaEstudando e guarde verdadeiro. Depois, mostre esses valores no console.”

Para let pontos = 0; e pontos = 10;, leia: “Comece com zero pontos. Depois, troque esse valor por dez.”

Exemplo comentado

// Valores que não precisam mudar
const nome = "Ana";
const idade = 30;
const estaEstudando = true;

console.log(nome);
console.log(idade);
console.log(estaEstudando);

// Este valor pode mudar
let pontos = 0;
pontos = 10;

console.log(pontos);

As três primeiras variáveis usam const. A variável pontos usa let porque seu valor muda de 0 para 10.

Erros comuns

  • Esquecer as aspas em um texto.
  • Colocar aspas em um número e transformá-lo em texto.
  • Tentar trocar o valor de uma variável criada com const.
  • Escrever True ou False com letra maiúscula.

Exercício básico

Crie variáveis para guardar:

  • seu nome;
  • sua idade;
  • se você está estudando JavaScript;
  • uma pontuação inicial.

Depois, mostre cada valor no console.

Como testar no console

  1. Abra as ferramentas do navegador com F12.
  2. Entre na aba Console.
  3. Digite ou cole as variáveis uma vez.
  4. Execute cada console.log() e confira o valor mostrado.

Resposta correta

// Troque os valores pelos seus dados
const meuNome = "Ana";
const minhaIdade = 30;
const estouEstudandoJavaScript = true;
let pontuacao = 0;

console.log(meuNome);
console.log(minhaIdade);
console.log(estouEstudandoJavaScript);
console.log(pontuacao);
Explicação da resposta
  • const meuNome = "Ana"; guarda um texto.
  • const minhaIdade = 30; guarda um número.
  • const estouEstudandoJavaScript = true; guarda o valor verdadeiro.
  • let pontuacao = 0; guarda a pontuação em uma variável que poderá mudar.
  • Cada console.log() mostra no console o valor da variável escrita entre os parênteses.

Aplicação prática no projeto

Nos projetos futuros, variáveis poderão guardar o nome de um botão, o texto de uma mensagem, a quantidade de itens, o estado de aberto ou fechado e uma pontuação ou progresso. Essas aplicações serão construídas aos poucos.

Aula 3

Operadores básicos: calculando, comparando e juntando valores

Objetivo

Entender como operadores calculam, juntam e comparam valores, além de começar a fazer perguntas que resultam em true ou false.

Explicação simples

Operadores são símbolos que dizem ao JavaScript o que fazer com os valores. Alguns devolvem um número, outros juntam textos e outros respondem verdadeiro ou falso.

Operadores matemáticos:

  • + soma números ou junta textos.
  • - faz uma subtração.
  • * faz uma multiplicação.
  • / faz uma divisão.
  • % encontra o resto de uma divisão.

O operador = faz uma atribuição: ele guarda um valor em uma variável. Já === compara dois valores e pergunta se eles são exatamente iguais.

Operadores de comparação:

  • === pergunta se os valores são iguais.
  • !== pergunta se os valores são diferentes.
  • > e < comparam qual valor é maior ou menor.
  • >= e <= também aceitam valores iguais na comparação.

Operadores lógicos:

  • && exige que as duas respostas sejam verdadeiras.
  • || exige que pelo menos uma seja verdadeira.
  • ! inverte verdadeiro e falso.

Por enquanto, use esses operadores apenas para montar perguntas simples. As decisões com condições serão assunto da próxima aula.

Como ler em português

  • preco - desconto: pegue o preço e tire o desconto.
  • "Olá, " + nome: junte o texto “Olá” ao nome.
  • total === 40: total é exatamente igual a 40?
  • temCadastro && pagou: tem cadastro E pagou?
  • temCadastro || pagou: tem cadastro OU pagou?
  • !pagou: inverta a resposta guardada em pagou.

Exemplo comentado

// Calcula o preço com desconto
const preco = 50;
const desconto = 10;
const total = preco - desconto;

console.log(total);

// O sinal de + junta textos
const nome = "Ana";
console.log("Olá, " + nome);

// Estas comparações respondem true ou false
console.log(total === 40);
console.log(total > 30);
console.log(total < 30);

// Combina e inverte respostas
const temCadastro = true;
const pagou = false;

console.log(temCadastro && pagou);
console.log(temCadastro || pagou);
console.log(!pagou);

Com números, + soma: 2 + 3 resulta em 5. Com textos, ele junta: "Olá, " + "Ana" resulta em "Olá, Ana".

Erros comuns

  • Usar = quando a intenção é comparar com ===.
  • Esperar uma soma ao usar + com um número entre aspas.
  • Escrever > = em vez de >=.
  • Confundir && com ||.

Exercício básico

Crie:

  • uma variável com o valor de um produto;
  • uma variável com o valor de um desconto;
  • uma variável com o preço final;
  • uma comparação para saber se o preço final é menor que 100;
  • as variáveis booleanas temCupom e freteGratis;
  • um teste usando && ou ||.

Mostre os resultados no console.

Como testar no console

  1. Abra as ferramentas do navegador com F12.
  2. Entre na aba Console.
  3. Digite as variáveis e pressione Enter.
  4. Execute os console.log() e observe os resultados.

Se você repetir uma variável criada com const e o mesmo nome, o navegador pode mostrar um erro. Recarregue a página e limpe as mensagens do console, ou use outro nome para a variável.

Resposta correta

const valorProduto = 120;
const valorDesconto = 30;
const precoFinal = valorProduto - valorDesconto;
const custaMenosDeCem = precoFinal < 100;

const temCupom = true;
const freteGratis = false;
const temBeneficio = temCupom || freteGratis;

console.log(precoFinal);
console.log(custaMenosDeCem);
console.log(temBeneficio);
Explicação da resposta
  • valorProduto guarda o número 120.
  • valorDesconto guarda o número 30.
  • precoFinal guarda o resultado da subtração: 90.
  • custaMenosDeCem guarda true, porque 90 é menor que 100.
  • temCupom guarda verdadeiro.
  • freteGratis guarda falso.
  • temBeneficio guarda true, pois o operador || precisa de apenas uma resposta verdadeira.
  • Os três console.log() mostram os resultados.

Aplicação prática no projeto

Nos projetos futuros, operadores poderão calcular totais, verificar se um item está completo, comparar valores, decidir se uma resposta deve aparecer e conferir se uma ação pode acontecer. Essa lógica será construída aos poucos.
