# AGENTS.md

## Objetivo do projeto

Guias de Programação é um site local de cursos para iniciantes, inicialmente focado no curso JavaScript Iniciante.

## Escopo atual

O projeto está em fase inicial. Priorize uma base simples, leitura confortável, boa organização e evolução incremental, sem antecipar complexidade.

## Stack permitida

Use somente:

- HTML;
- CSS;
- JavaScript puro.

Não use React, Vue, Vite, TypeScript, banco de dados, autenticação, dependências externas ou frameworks CSS.

## Regras para alterações

- Faça mudanças pequenas, focadas e fáceis de revisar.
- Preserve o visual atual, salvo quando a tarefa pedir uma mudança visual.
- Não reorganize ou mova arquivos sem uma necessidade clara.
- Não produza grandes volumes de conteúdo de uma só vez.
- Mantenha comentários curtos em português quando explicarem a intenção do código.
- Ao finalizar, explique o que foi alterado e por quê.
- Preserve a execução local com `npx serve . -l 8000`.

## Regras para o conteúdo das aulas

- Escreva de forma simples, objetiva e adequada a iniciantes.
- Explique termos técnicos antes de usá-los como conhecimento prévio.
- Não tente ensinar todo o JavaScript em uma única aula.
- Use exemplos curtos e relacionados ao assunto da aula.
- Reforce a seção **Como ler em português** em cada aula.
- Proponha exercícios básicos com resposta comentada.

## Modelo didático desejado

Sempre que possível, organize cada aula assim:

1. Objetivo
2. Explicação simples
3. Como ler em português
4. Exemplo
5. Exercício
6. Resposta comentada
7. Aplicação prática, quando fizer sentido

## Projetos práticos

Existem dois projetos planejados:

- Landing Page Interativa;
- Mini Checklist.

Construa esses projetos aos poucos, acompanhando os conceitos apresentados nas aulas.

## Usabilidade e acessibilidade

- Priorize leitura confortável e bom contraste.
- Preserve a navegação por teclado e estados de foco visíveis.
- Evite animações exageradas.
- Respeite a preferência de redução de movimento do usuário.

## O que evitar nesta fase

- Transformar o projeto em uma aplicação complexa.
- Adicionar backend ou banco de dados.
- Criar login, autenticação ou painel administrativo.
- Separar o conteúdo em muitas páginas cedo demais.
- Gerar muitas aulas de uma só vez.
